# Timeline Log — Date, Time, Place

*Started July 21, 2026. See [photography-philosophy.md](photography-philosophy.md) — photos as "mile markers, marking a place and point in time." This is the same idea in text form, built from receipts now and photo EXIF data (timestamp + GPS) eventually.*

A single flat, chronological log. Deliberately loose schema — each entry carries whatever fields its source actually provides, not a fixed column set. New fields (flight/segment, airline, miles flown, and anything else that turns out to be worth tracking) get added as they come up, without needing to restructure past entries. Claude will ask before adding a new recurring field, rather than assume it's wanted.

---

## Entry Format

```
## YYYY-MM-DD

**Time:** (if known)
**Place:** Vendor/location name, city, state
**Source:** Receipt / Photo / other
**Notes:** (optional — anything else worth keeping)

---
```
