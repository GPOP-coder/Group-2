# Timeline Log — Date, Time, Place

*Started July 21, 2026. See [photography-philosophy.md](photography-philosophy.md) — photos as "mile markers, marking a place and point in time." This is the same idea in text form, built from receipts now and photo EXIF data (timestamp + GPS) eventually.*

A single flat, chronological log. Deliberately loose schema — each entry carries whatever fields its source actually provides, not a fixed column set. New fields get added as they come up, without needing to restructure past entries. Claude will ask before adding a new recurring field, rather than assume it's wanted.

**Expanded 7/23/26** to support future reconciliation against bank/card statements, Quicken Simplifi, and QuickBooks — not just "where was I," but "can I match this to a statement line or an expense report later."

---

## Entry Format

```
## YYYY-MM-DD  (Transaction/Purchase Date — when the charge posted; what a statement search matches)

**Event/Service Date:** (only if different from the date above — flights, hotels, rentals: when the thing actually happened)
**Time:** (if known)
**Place:** Vendor/location name, full address if printed, city, state
**Amount:** (total charged)
**Payment Method:** (card/account — match how cards are labeled in finances/cards.md, e.g. "Visa -0733 FNBO Evergreen")
**Merchant as billed:** (only if different from the display/storefront name — what actually shows up on the statement)
**Flight Number(s):** (flights only, e.g. "WN #2606")
**Miles Flown:** (flights only — usually not on the receipt; compute later from origin/destination once logged, or use if an airline loyalty program reports actual miles directly)
**Points Earned:** (flights/hotels only, if the receipt reports it — e.g. Southwest's "Est. Points Earned," SkyMiles, Rapid Rewards)
**Reference/Confirmation #:** (auth code, confirmation number, invoice/ticket number)
**Business Context:** (Personal / PWS / eBay-Photography / BTTR / NTSG / Father's POA)
**Source Filename:** (the actual receipt file this entry came from)
**Source:** Receipt / Photo / other
**Notes:** (optional — anything else worth keeping)

---
```

Not every entry needs every field — most personal receipts (gas, groceries) will only need Time/Place/Amount/Payment Method/Source Filename. The fuller set exists for the entries that actually carry that data (flights, hotels, business expenses).
