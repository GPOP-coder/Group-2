# Unifocus Labor Management System — Manager Training Guide

**Scope:** 3-hour training session for property managers  
**Trainer:** Pete Castellano (PWS) | Akram Chahin (Unifocus) | Consultants  
**Format:** Live facilitation + hands-on exercises  
**Prerequisites:** Active Unifocus login, laptop with browser, Teams access (remote sessions)

---

## Training Agenda — 3 Hours

### 1. Navigation (15 min)
**Portal:** www.portal.unifocus.com

**Facilitator Key Points:**
- Ensure all users can log in before session begins
- Walk through user profile setup (password, preferences)
- Show Help Section (Videos, Portal, Open Uni Sessions) — critical resource for self-service
- Orient to Unifocus main menu structure and how to navigate between modules

**Video:** (None in standard agenda)

---

### 2. Planning Menu (30 min)
**Video:** https://www.unifocus.com/vid/qrv-fprms10

**Facilitator Key Points:**
- **LMS Timeline** — explain the planning cycle and deadlines
- **Environments** — what they are, how they're structured at this property
- **Forecast (Rooms, Banquets, F&B and other Revenue Centers)** — how forecast data drives labor planning
- **Project Hours and Generate Schedules** — the bridge between forecast and labor
- **Manage/Publish Schedules** — workflow and approvals

**Hands-On Exercise:**
- Managers navigate to their property's Forecast
- View current week's revenue center data
- Project hours for one revenue center

---

### 3. Scheduling (60 min)
**Video:** https://www.unifocus.com/vid/qrv-sch-rms10

**Facilitator Key Points:**

**Navigation & Viewing:**
- Main navigation buttons and their purpose
- Changing the Week (move between weeks, navigate to future periods)
- Sort Functions (by job, by employee, custom sorts)
- Filter Jobs (show/hide secondary jobs, filter by department)
- View Options (Hide Unscheduled Secondary Jobs, toggle visibility)
- Show Daily Summary (Scheduled vs. Projected Hours comparison)
- Show KBI Data (view current forecast alongside schedule)
- Save View (lock in preferred layout for next session)

**Editing Shifts:**
- Create/Edit Shifts (from scratch, modify existing)
- Copy/Paste Shifts (duplicate shifts across days/weeks)
- Drag and Drop Shifts (assign to different employees)
- Explain Icons and Labels (what visual cues mean)

**Schedule Management:**
- Delete, Restore, and Copy Schedules (undo options, weekly copies)
- Manage/Publish and Print Schedules (workflow to publish, print formats)

**Hands-On Exercise:**
- Managers open their property's current week schedule
- Filter to one job code, view KBI data
- Create one shift, copy it to another day
- Practice drag-and-drop assignment
- Save a view preference

---

### 4. Employee Maintenance (20 min)
**Video:** https://www.unifocus.com/vid/qrv-em-rms10

**Facilitator Key Points:**
- **Regular Schedules** — template schedules, how they're used
- **Availability** — employee availability windows (days, shift times)
- **Scheduling Groups** — how employees are grouped for assignment
- **Assignments** — job assignments (which job codes each employee can work)
- **Secondary Job Codes** — cross-training, job flexibility
- **Sub Only Feature** — how to flag employees as substitute-only or limited availability

**Hands-On Exercise:**
- Managers view one employee's profile
- Review their assignment and availability
- Add or modify one secondary job code (if applicable)

---

### 5. Employee Request (10 min)
**Video:** https://www.unifocus.com/vid/qrv-ta-rms10

**Facilitator Key Points:**
- **Create Time Off Requests** — how employees request days off (if portal-enabled)
- **Approve Requests** — manager workflow for approving/denying requests
- Timing and impact on scheduling

**Demo Only:**
- Show a sample time-off request
- Walk through approval workflow
- Explain how system flags conflicts

---

### 6. Actuals (15 min)
**Video:** (None — no video linked in standard agenda)

**Facilitator Key Points:**
- **Enter Actual KBIs** — how actual business metrics are recorded (guests, covers, events)
- **Generate Standard Hours** — system calculation based on actual KBIs and labor standards
- **Enter Actual Hours (Contract Labor)** — manual entry for contractors, outside labor

**Hands-On Exercise:**
- Managers view Actuals entry screen for current week
- Walk through one sample data entry (if test data available)

---

### 7. Reports & Dashboard (20 min)
**Video:** https://www.unifocus.com/vid/qrv-repter-rms10

**Facilitator Key Points:**
- **Labor Effectiveness Report** — comparing scheduled vs. actual hours, variance analysis
- **Weekly Labor Summary** — high-level week snapshot, total labor cost
- **File Types (PDF, Excel, CSV, etc.)** — export options for different uses
- **Schedule Reports** — employee schedules, coverage reports, compliance
- **Labor Dashboard** — real-time labor metrics, KPI tracking

**Hands-On Exercise:**
- Managers run one Labor Effectiveness Report for their property
- Export to Excel
- Identify one insight from the data

## Success Criteria — End of Session

Managers should be able to:
- [ ] Log in and navigate the Unifocus portal
- [ ] View their property's forecast and current schedule
- [ ] Create, edit, and assign shifts
- [ ] Filter and sort schedule views to their preference
- [ ] Review employee availability and assignments
- [ ] Process time-off requests
- [ ] Run and interpret a labor report
- [ ] Know where to find help for questions after training
