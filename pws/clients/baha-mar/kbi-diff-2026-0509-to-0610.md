## Executive Summary

The 5/9 → 6/10 configuration update is a single, coordinated project: **Rosewood Baha Mar BQT and Available Guests integration into campus and resort-level rollup KBIs.** Every aggregate formula that previously summed only SLS and Grand Hyatt data has been updated to include the corresponding Rosewood KBI. Supporting this integration required:

- Adding Rosewood mirror BQT KBIs to the GH and SLS files
- Adding new infrastructure KBIs for Rosewood stayovers and occupancy yesterday to CTF
- Correcting three pre-existing formula bugs (CTF departure formula, SLS GH Arr+Dep code, ROS GH Departures formula) as part of the same update
- Completely rebuilding the Rosewood property file with Baha Mar-specific outlets (Cafe Boulud, Costa, IRD), a Loc banquet structure, and GH mirror BQT KBIs
